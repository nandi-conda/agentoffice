# upload: Workstation

The program on the desk computers: your notes, todo list, bookmarks, a focus timer and the office shell. The office runs it for whoever sits at a desk; placed on the floor it only says so. People see it as “Look at the screen”.

- an example upload: `public/plugins/workstation.wasm`, built from `plugins/wasm-workstation` with the agentoffice-plugin crate, whose manifest these actions come from
- put it on the map from the 🧩 panel ("try the example") or with `gallery_upload`, then use it with the MCP tool `uobj_interact` (name = its `u-…` id from `gallery_view`, action = one of these, input = the typed text)
